# CONN-BELLWETHER-MCP-FOMC-ANNOUNCEMENTS — Requirements

Governing spec: [spec.md](spec.md).

| ID | Requirement | Acceptance |
|---|---|---|
| `CONN-BELLWETHER-MCP-FOMC-ANNOUNCEMENTS-R001` | **Historical release time.** The curated FOMC calendar returns each existing decision's sourced UTC announcement time. Caller chain: the bellwether-mcp console script (bellwether_mcp/mcp_server.py::mcp_server) builds the server via bellwether_mcp/mcp/server.py::build_server, which calls bellwether_mcp/mcp/tools_fomc_calendar.py::register_fomc_calendar_tools and serves fomc_calendar_list, which calls bellwether_mcp/api/fomc_calendar.py::list_meetings. Shape: load_meetings (line 32) and _record (line 49) in bellwether_mcp/api/fomc_calendar.py build each record from the curated dataset with its sourced UTC announcement time. | `tests/test_api_fomc_calendar.py` checks UTC timestamps, representative standard and daylight time releases, the corrected January 2026 source, and the returned record. Test: `tests/test_api_fomc_calendar.py::test_returned_announcement_times_match_sourced_release_dates`. |
| `CONN-BELLWETHER-MCP-FOMC-ANNOUNCEMENTS-R002` | **Declared SDK source.** The declared FOMC source retains the curated announcement time and source URL through the SDK MCP adapter. Caller chain: the declared FOMC source is read by the scion_sdk MCP source adapter over the served fomc_calendar_list tool registered through bellwether_mcp/__init__.py::connector, down to bellwether_mcp/api/fomc_calendar.py::list_meetings. Shape: the packaged source mapping loaded through ConnectorContent.for_package maps the record announcement time and source URL fields returned by _record. | `tests/test_api_fomc_calendar.py` extracts the served source through the SDK transport. Test: `tests/test_api_fomc_calendar.py::test_declared_fomc_source_retains_announcement_through_sdk`. |
| `CONN-BELLWETHER-MCP-FOMC-ANNOUNCEMENTS-R003` | **Calendar date bounds.** Explicit FOMC date bounds use canonical calendar dates and form an ordered range. Equal bounds include that day. Caller chain: the bellwether-mcp console script (bellwether_mcp/mcp_server.py::mcp_server) builds the server via bellwether_mcp/mcp/server.py::build_server, which calls bellwether_mcp/mcp/tools_fomc_calendar.py::register_fomc_calendar_tools and serves fomc_calendar_list, which calls bellwether_mcp/api/fomc_calendar.py::list_meetings. Shape: _date_bound (line 63) parses canonical dates, _validate_date_range (line 74) enforces order with equal bounds allowed, and _matches_filters (line 80) applies the inclusive range. | `tests/test_api_fomc_calendar.py` covers served refusal and inclusive bounds. Test: `tests/test_api_fomc_calendar.py::test_served_fomc_refuses_invalid_date_ranges`. |
