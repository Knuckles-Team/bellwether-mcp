# CONN-BELLWETHER-MCP-CMC-PAGING — Requirements

Governing spec: [spec.md](spec.md).

| ID | Requirement | Acceptance |
|---|---|---|
| `CONN-BELLWETHER-MCP-CMC-PAGING-R001` | **Start listings at the first record.** The served CMC listings tool defaults to zero-based offset zero and translates explicit offsets to the provider's one-based start. Caller chain: the bellwether-mcp console script (bellwether_mcp/mcp_server.py::mcp_server) builds the server via bellwether_mcp/mcp/server.py::build_server, which calls bellwether_mcp/mcp/tools_crypto_reference.py::register_crypto_reference_tools and serves the cmc_listings tool, which calls bellwether_mcp/api/coinmarketcap.py::list_listings. Shape: list_listings in bellwether_mcp/api/coinmarketcap.py (line 93) converts the zero-based offset to the provider start; the cmc_listings tool in bellwether_mcp/mcp/tools_crypto_reference.py passes start and limit through. | `tests/test_api_coinmarketcap.py` exercises default and explicit offsets through the served MCP tool. Test: `tests/test_api_coinmarketcap.py::test_served_default_listings_start_at_first_provider_record`. |
| `CONN-BELLWETHER-MCP-CMC-PAGING-R002` | **SDK source paging.** The declared CMC listings source pages through the SDK MCP adapter without skipping records. Caller chain: the declared CMC source is read by the scion_sdk MCP source adapter over the served cmc_listings tool (bellwether_mcp/mcp/tools_crypto_reference.py::register_crypto_reference_tools) registered through bellwether_mcp/__init__.py::connector, down to bellwether_mcp/api/coinmarketcap.py::list_listings. Shape: the source mapping ships in the packaged connector content loaded by scion_sdk.mcp.content.ConnectorContent.for_package in bellwether_mcp/mcp/server.py; paging uses the offset and limit arguments of list_listings with no bespoke pager. | `tests/test_api_coinmarketcap.py` extracts two served pages with the SDK transport and source adapter. Test: `tests/test_api_coinmarketcap.py::test_sdk_source_adapter_pages_served_cmc`. |
| `CONN-BELLWETHER-MCP-CMC-PAGING-R003` | **Valid page bounds.** Listing offsets are nonnegative integers and limits are positive integers. Invalid bounds refuse before the provider request. Caller chain: the bellwether-mcp console script (bellwether_mcp/mcp_server.py::mcp_server) builds the server via bellwether_mcp/mcp/server.py::build_server, which calls bellwether_mcp/mcp/tools_crypto_reference.py::register_crypto_reference_tools and serves the cmc_listings tool, which calls bellwether_mcp/api/coinmarketcap.py::list_listings. Shape: validate_offset_page in bellwether_mcp/api/_pagination.py raises ValueError for negative or non-integer offsets and non-positive limits; list_listings calls it before building the provider request. | `tests/test_api_coinmarketcap.py` covers served refusal and direct client validation. Test: `tests/test_api_coinmarketcap.py::test_served_cmc_rejects_invalid_page_before_vendor_call`. |
