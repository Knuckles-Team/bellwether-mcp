# CONN-BELLWETHER-MCP-CMC-VALUES — Requirements

Governing spec: [spec.md](spec.md).

| ID | Requirement | Acceptance |
|---|---|---|
| `CONN-BELLWETHER-MCP-CMC-VALUES-R001` | **Finite market values.** Listing, quote and global-metric numeric fields refuse non-finite or non-numeric values. Null fields remain null. Caller chain: the bellwether-mcp console script (bellwether_mcp/mcp_server.py::mcp_server) builds the server via bellwether_mcp/mcp/server.py::build_server, which calls bellwether_mcp/mcp/tools_crypto_reference.py::register_crypto_reference_tools and serves the cmc_listings tool, which calls bellwether_mcp/api/coinmarketcap.py::list_listings or get_quotes or get_global_metrics. Shape: _finite_number in bellwether_mcp/api/coinmarketcap.py (line 26) rejects non-finite and non-numeric values and keeps None; _listing_record, _quote_usd and _global_usd apply it to each numeric field. | `tests/test_api_coinmarketcap.py` checks served refusal and null preservation. Test: `tests/test_api_coinmarketcap.py::test_served_cmc_refuses_invalid_numeric_values`. |
| `CONN-BELLWETHER-MCP-CMC-VALUES-R002` | **Response data shape.** Listing and quote pages require their data collections. Global metrics require a USD quote. Missing or malformed data refuses instead of producing an empty result. Caller chain: the bellwether-mcp console script (bellwether_mcp/mcp_server.py::mcp_server) builds the server via bellwether_mcp/mcp/server.py::build_server, which calls bellwether_mcp/mcp/tools_crypto_reference.py::register_crypto_reference_tools and serves the cmc_listings tool, which calls bellwether_mcp/api/coinmarketcap.py::list_listings or get_quotes or get_global_metrics. Shape: _required_data (line 38) enforces the expected collection type and _global_usd (line 44) requires the USD quote; an empty valid collection is returned unchanged. | `tests/test_api_coinmarketcap.py` exercises served refusal and valid empty collections. Test: `tests/test_api_coinmarketcap.py::test_served_cmc_refuses_missing_or_invalid_data`. |
| `CONN-BELLWETHER-MCP-CMC-VALUES-R003` | **Provider identity.** Listings and quotes require a positive integer CMC asset ID. Invalid or missing IDs refuse instead of producing a fabricated string identity. Caller chain: the bellwether-mcp console script (bellwether_mcp/mcp_server.py::mcp_server) builds the server via bellwether_mcp/mcp/server.py::build_server, which calls bellwether_mcp/mcp/tools_crypto_reference.py::register_crypto_reference_tools and serves the cmc_listings tool, which calls bellwether_mcp/api/coinmarketcap.py::list_listings or get_quotes or get_global_metrics. Shape: _cmc_id (line 67) in bellwether_mcp/api/coinmarketcap.py accepts only a positive integer id and is used by _listing_record and the quote flattening. | `tests/test_api_coinmarketcap.py` covers served refusal for listings and quotes. Test: `tests/test_api_coinmarketcap.py::test_served_cmc_refuses_invalid_provider_identity`. |
| `CONN-BELLWETHER-MCP-CMC-VALUES-R004` | **Unique page identities.** Listings and quote pages refuse repeated asset IDs. A page cannot return conflicting records for one asset identity. Caller chain: the bellwether-mcp console script (bellwether_mcp/mcp_server.py::mcp_server) builds the server via bellwether_mcp/mcp/server.py::build_server, which calls bellwether_mcp/mcp/tools_crypto_reference.py::register_crypto_reference_tools and serves the cmc_listings tool, which calls bellwether_mcp/api/coinmarketcap.py::list_listings or get_quotes or get_global_metrics. Shape: _require_unique_records (line 87) in bellwether_mcp/api/coinmarketcap.py raises on a repeated asset id and is applied to listings and quote pages. | `tests/test_api_coinmarketcap.py` exercises repeated IDs through both served tools. Test: `tests/test_api_coinmarketcap.py::test_served_cmc_refuses_duplicate_asset_ids`. |
