# CONN-BELLWETHER-MCP-FRED-VINTAGE — Requirements

Governing spec: [spec.md](spec.md).

| ID | Requirement | Acceptance |
|---|---|---|
| `CONN-BELLWETHER-MCP-FRED-VINTAGE-R001` | **Validate point-in-time windows.** The FRED client requires a canonical calendar date for each explicit real-time bound. The as-of operation requires a date and pins both bounds. Invalid or reversed bounds refuse before any vendor request. Caller chain: the bellwether-mcp console script (bellwether_mcp/mcp_server.py::mcp_server) builds the server via bellwether_mcp/mcp/server.py::build_server, which calls bellwether_mcp/mcp/tools_macro_series.py::register_macro_series_tools and serves the fred_series_observations, fred_series_observations_asof and fred_series_vintage_dates tools, which call bellwether_mcp/api/fred.py. Shape: _require_realtime_date (line 77) and _realtime_params (line 90) validate each bound before get_observations (line 101) or get_observations_asof (line 142) issues a request. | `tests/test_api_fred.py` checks the API and served MCP path, valid dates and zero vendor calls on refusal. Test: `tests/test_api_fred.py::test_invalid_explicit_realtime_windows_never_request`. |
| `CONN-BELLWETHER-MCP-FRED-VINTAGE-R002` | **Finite observations.** FRED observations refuse non-finite values. The missing-value marker remains a null value. Caller chain: the bellwether-mcp console script (bellwether_mcp/mcp_server.py::mcp_server) builds the server via bellwether_mcp/mcp/server.py::build_server, which calls bellwether_mcp/mcp/tools_macro_series.py::register_macro_series_tools and serves the fred_series_observations, fred_series_observations_asof and fred_series_vintage_dates tools, which call bellwether_mcp/api/fred.py. Shape: _finite_value (line 33) in bellwether_mcp/api/fred.py rejects non-finite numbers while _parse_observation_value (line 26) keeps the missing marker as None. | `tests/test_api_fred.py` checks refusal through the served tool and existing missing-value behavior. Test: `tests/test_api_fred.py::test_served_fred_refuses_nonfinite_observations`. |
| `CONN-BELLWETHER-MCP-FRED-VINTAGE-R003` | **Observation page shape.** A FRED page has an observations list of objects. A missing or malformed list refuses; an empty list is valid. Caller chain: the bellwether-mcp console script (bellwether_mcp/mcp_server.py::mcp_server) builds the server via bellwether_mcp/mcp/server.py::build_server, which calls bellwether_mcp/mcp/tools_macro_series.py::register_macro_series_tools and serves the fred_series_observations, fred_series_observations_asof and fred_series_vintage_dates tools, which call bellwether_mcp/api/fred.py. Shape: _required_page (line 40) in bellwether_mcp/api/fred.py requires a list of objects for the named field and accepts an empty list. | `tests/test_api_fred.py` exercises refusal through the served tool and a valid empty page. Test: `tests/test_api_fred.py::test_served_fred_refuses_malformed_observation_pages`. |
| `CONN-BELLWETHER-MCP-FRED-VINTAGE-R004` | **Observation identity.** Each observation has canonical calendar dates for its period and vintage, and an explicit value. A malformed or missing field refuses the page. Caller chain: the bellwether-mcp console script (bellwether_mcp/mcp_server.py::mcp_server) builds the server via bellwether_mcp/mcp/server.py::build_server, which calls bellwether_mcp/mcp/tools_macro_series.py::register_macro_series_tools and serves the fred_series_observations, fred_series_observations_asof and fred_series_vintage_dates tools, which call bellwether_mcp/api/fred.py. Shape: _observation_fields (line 49) and _observation_record (line 57) require canonical period and vintage dates and an explicit value, else raise. | `tests/test_api_fred.py` exercises refusal through the served tool. Test: `tests/test_api_fred.py::test_served_fred_refuses_missing_or_invalid_identity`. |
| `CONN-BELLWETHER-MCP-FRED-VINTAGE-R005` | **Vintage-date page shape.** A FRED vintage-date page carries a list of canonical calendar dates. A missing or malformed list refuses; an empty list is valid. Caller chain: the bellwether-mcp console script (bellwether_mcp/mcp_server.py::mcp_server) builds the server via bellwether_mcp/mcp/server.py::build_server, which calls bellwether_mcp/mcp/tools_macro_series.py::register_macro_series_tools and serves the fred_series_observations, fred_series_observations_asof and fred_series_vintage_dates tools, which call bellwether_mcp/api/fred.py. Shape: get_vintage_dates (line 168) in bellwether_mcp/api/fred.py uses _required_page and validates each entry as a canonical date. | `tests/test_api_fred.py` exercises served refusal and a valid empty page. Test: `tests/test_api_fred.py::test_served_vintage_dates_refuse_malformed_pages`. |
| `CONN-BELLWETHER-MCP-FRED-VINTAGE-R006` | **Declared SDK source.** The declared FRED source pages through the SDK MCP adapter and retains the reported vintage and source provenance. Caller chain: the declared FRED source is read by the scion_sdk MCP source adapter over the served fred_series_observations tool registered through bellwether_mcp/__init__.py::connector, down to bellwether_mcp/api/fred.py::get_observations.
